### Projects

#### Kubernetes security & compliance

* **[kshield](https://github.com/sv222/kshield)** - Security scanner for Kubernetes AI workloads (vLLM, Ollama, Triton, TGI, KubeRay, KServe, Qdrant, Milvus and more). Produces DORA evidence reports (PDF, HTML, JSON, SARIF) with signed evidence bundles, and generates Cilium, Tetragon and Kyverno remediation policies.
* **[k8s-remediate-nis2](https://github.com/sv222/k8s-remediate-nis2)** - Turns failed Prowler and kube-bench checks (EKS, AKS, GKE) into Kyverno policies and Terraform fixes, mapped to NIS2, DORA and ISO 27001.

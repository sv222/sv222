#### Projects

* **[kshield](https://github.com/sv222/kshield)** — Kubernetes AI workload scanner with DORA evidence reports. Checks vLLM, Ollama, KubeRay, KServe, Qdrant and Milvus, writes text, JSON, HTML, PDF and SARIF reports, signed evidence bundles, and Cilium, Tetragon and Kyverno remediation policies.
* **[ai-guard-k8s](https://github.com/sv222/ai-guard-k8s)** — CLI to scan and harden Kubernetes AI inference workloads (vLLM, Ollama, Triton, Ray). Scans Helm charts and Kustomize overlays, generates Kyverno & Cilium policies, SARIF for GitHub code scanning.
* **[k8s-remediate-nis2](https://github.com/sv222/k8s-remediate-nis2)** — CLI that turns failed Prowler (JSON and ASFF) & kube-bench checks, including EKS, AKS and GKE, into Kyverno policies and Terraform fixes mapped to NIS2, DORA and ISO 27001.
* **[pivotlens](https://github.com/sv222/pivotlens)** — Terminal viewer for CSV, Parquet, and NDJSON backed by embedded DuckDB, with pivot tables, totals and percent views.
* **[portpin](https://github.com/sv222/portpin)** — Deterministic process-to-port terminator for Linux, macOS & Windows, with safe process-group kill and JSON output.
